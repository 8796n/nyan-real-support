nyan Real / Spatial Wall ユーザーマニュアル

メガネをかけると、目の前の空間に複数のディスプレイが並びます。 頭を動かすと視点が移動しますが、ディスプレイはその場に留まります。 このマニュアルでは、接続から基本設定、使い方、トラブル対処までを説明します。

個々の設定項目の説明は、アプリ内でその項目にマウスを重ねると出ます。 ここではその手前にある「何のために、どういう順番で使うか」を扱います。

本文と画面は 2026 年 9 月 10 日の 0.9.0 開発版に合わせています。画像は Windows 版に XREAL 1S を接続し、マスタースイッチをオンにした状態です。OS や接続機種によって、 表示される設定・操作項目は変わります。

このアプリについて

対応するメガネを USB でつなぐと、PC のディスプレイをウォールとして 空間に並べ、頭の動きに合わせて描き直します。ディスプレイは物理・仮想を 問わず並べられ、音も画面の位置から聞こえるようになります。

主な機能は 2 つです。

  • Display Wall — 複数のディスプレイを空間に並べて表示します。OS 側の ディスプレイ配置がそのままウォールになるのが基本の考え方で、普段どおり OS の「画面の配置」を変えれば、空間の並びもそのとおりに変わります。1 枚に 集中したり、屏風のように折り曲げたり、距離を変えたりもできます。
  • Audio Wall — 再生中のアプリを自動で見つけ、そのウィンドウがある方向から 音が鳴るように混ぜます。アプリごとの設定は要りません。

インターネット上の外部サーバーとは通信しません。 更新の自動確認や、利用状況・ クラッシュ情報の送信も行いません。ネットワーク通信を使う機能は、次のローカル経路だけです。

  • スマホリモコン / Android メガネブリッジ — 同じ LAN 上の端末との通信
  • XREAL One 系との接続 — USB Ethernet 経由の TCP/IP 通信でメガネ本体と直接通信
  • Chrome 拡張からのタブ音声 — 同じ PC 内のループバック（127.0.0.1）
  • Stream Deck などからのローカル操作 — 同じ PC 内のループバック（127.0.0.1）

サポートも自動化していません。不具合の報告は、「バージョン情報」から情報をコピーして GitHub Issues に貼る、という手動の流れです。

対応メガネ：XREAL（One Pro / One / 1S / Air 2 Pro / Air 2 / Air）、 ROG XREAL R1、xbx a01 / a01+、RayNeo Air、Rokid（Max / Air）、 VITURE（Pro / One / One Lite）、EPSON MOVERIO（BT-40 / BT-30C）、Nreal Light、 MAD Gaze Glow。機種ごとにできることが違うので、詳しくは 対応メガネ一覧 を見てください。

動作環境：Windows のほか、Linux と macOS でも同じアプリが動きます。

OS 動作要件
Windows Windows 10 バージョン 2004（build 19041）以降の 64 ビット版
Linux（GNOME） GNOME 46 以降（Wayland セッション）
Linux（Raspberry Pi） Raspberry Pi OS trixie 以降 + labwc
macOS macOS 14.4 以降（実験的。一部の機能が未対応です）

どの環境でも、映像出力できる USB-C ポートまたは HDMI 変換アダプターと、メガネ本体が 要ります。インターネット接続は必須ではありません。スマホリモコンや Android メガネ ブリッジを使う場合は、スマホと PC が同じ LAN に接続されている必要があります。OS ごとの機能差は 付録の表にまとめてあります。

インストールと最初の起動

Windows

インストーラー（nyan-real-spatial-wall-*-installer.exe）とポータブル ZIP の どちらでも動きます。ポータブル版は展開して spatial-wall.exe を実行するだけで、 インストールは不要です。

署名について：現在の配布物にはコード署名がないため、初回起動時に Windows の SmartScreen が警告を出すことがあります。「詳細情報」→ 「実行」で進めてください。

Linux（GNOME）

.deb パッケージを apt install で導入します。仮想ディスプレイは GNOME の 画面共有機能（Mutter ScreenCast）を使うので、追加のドライバーは要りません。 導入・更新後は一度ログアウトして再ログインし、同梱の GNOME Shell 連携を有効にしてください。 連携が無効という警告が出ている間は、集中モードや、通常ディスプレイなしでメガネと 仮想ディスプレイだけを使う構成など、一部の機能が制限されます。

Linux（Raspberry Pi / labwc）

専用の .deb を導入します。仮想ディスプレイは labwc の機能を使います。 インストール時に udev ルールが入り、メガネへ USB でアクセスできるようになります。

macOS

実験的な対応です。購入時または配布時に案内された最新版を使い、同梱の README で対応アーキテクチャと署名状態を確認してください。

どの環境でも、起動後の使い方はこの先で共通です。

起動すると常駐アイコンが表示されます。Windows 版と Linux 版ではタスクトレイ、 macOS 版ではメニューバーに常駐します。ウィンドウを閉じても終了しません。 常駐アイコンから再表示でき、アイコンのメニューで「終了」を選ぶと終了します。

最初に見えるのは、上部の操作パネルと、左側のカテゴリ一覧です。

  • 有効 — マスタースイッチです。オフにするとメガネへの映像出力、センサー接続、 Audio Wall が止まります。仮想ディスプレイの扱いは後述の接続構成によって変わります。
  • 3DoF（頭の動きへの追従） — オフにすると、通常はウォールが視界に固定されます。 「メガネ」の「3DoF オフ時のジンバル」をオンにすると、大きな首振りにだけ滑らかに追従します。
  • センターに移動 — 今向いている方向を正面として、ウォールを配置し直します。
  • ウォールマップ — ウォールを小さな平面図で表示します（後述）。

メガネをまだつないでいなくても設定をひととおり確認・変更できます。接続したメガネが 検出されて頭の追従が始まると、状態表示が「3DoF 動作中」に変わります。

メガネをつなぐ

マスタースイッチをオンにして USB でつなぐと自動で検出されます。上部の状態表示 （「3DoF 動作中」など）を押すと、検出した機種、IMU の経路、メガネ画面を確認できます。 メガネのカテゴリでは、表示モードや SBS 出力、FoV などを設定します。

通常のメガネ表示は、独立した拡張ディスプレイである必要があります。 複製表示や「セカンドスクリーンのみ」だと、ウォールが取り込むはずの画面が 隠れてしまうためです。既定では自動で拡張ディスプレイに切り替え、デスクトップの 隅へ寄せます。この隅は他のディスプレイと 1 点だけで接するので、カーソルや ドラッグ中のウィンドウがメガネ側へはみ出しません。複製中はメガネと相手画面が同じ 表示元を共有するため、独立した拡張画面への切り替えが完了するまでウォール出力を開始しません。 Windows では無効化された対応メガネも再有効化します。

条件付き機能として、実機 EDID に Microsoft HMD VSDB を持つ表示モードでは、Windows がメガネを HeadMounted と分類してデスクトップから外します。Spatial Wall はこの状態を自動検出し、 メガネを排他取得して直接表示します。一般のメガネを HMD 化する機能ではありません。 HMD モード中は、拡張画面の設定、隅寄せ、メガネ側のカーソルフェンス、 フルスクリーン排他は使用しません。対応条件と実機確認済みの構成は、付録の 「検証済み構成と既知の制限」を参照してください。

つないだら次を確認してください。

  1. 表示モード — 2D か 3D SBS か、リフレッシュレートを選びます。 対応機種では 72 Hz / 90 Hz 系のモードで OLED のデューティ比も下がり、見回したときの 残像が減ります。「保存した表示モードを接続時に復元」は既定でオフです。 オフでも手動選択は記憶され、通常モードの復元にも使えます。最後に記憶したのが HMD 対応モードの場合は、その切り替えが安定する PC でだけオンにしてください。
  2. SBS 出力 — 「自動」のままで、たいていのモードは正しく判別されます。 ハーフ SBS のモードだけは解像度から判別できないので、手動でオンにします。
  3. 明るさ / 音量 — 上部の操作パネルで変更します。メガネ側で調整できる機種では、 明るさや内蔵アンプ音量など、その機種に対応した操作が表示されます。 メガネ内蔵アンプの音量と PC 側の音量は掛け算になるので、PC 側が 100% でも 小さいときはメガネ側を上げてください。

タップ操作（対応機種のみ）

メガネのツルを 2 回 / 3 回叩くと、再生・一時停止や 音量、センターに移動などを実行できます。反応が悪いときは「タップ操作」の カテゴリから較正してください。メガネに指示が表示されます。

居眠り対策

しばらく動かないとスリープに入り、画面を消します。 動かせば戻ります。時間と感度は「省電力」で変えられます。

ウォールを組む

Display Wall のカテゴリで、どのディスプレイを並べるかと、どう並べるかを 決めます。

並べるディスプレイを選ぶ

図には OS 側の現在のディスプレイ配置が表示されます。タイルをクリックすると、 そのディスプレイをウォールに含めるかどうかが切り替わります。除外したタイルは 薄く表示され、ウォールを空にしないよう最後の 1 枚は除外できません。また、Spatial Wall が追加した仮想ディスプレイがメイン画面になっている間は、そのタイルも除外 できません。先に別の画面をメインにしてから除外してください。メガネ自身の ディスプレイはウォールには含まれません。

並べ方を決める

Spatial Wall にはレイアウト方式の選択はなく、OS のディスプレイ配置がそのまま ウォールになります。図のタイルをドラッグすると配置を編集できます。表示された 適用を押すと OS 側のディスプレイ配置も変更され、キャンセルを押すと編集前の 配置に戻ります。OS のディスプレイ設定で配置を変えた場合も、ウォールに反映されます。

「ディスプレイの枠を表示」をオンにすると、隣り合うディスプレイの間に細い黒線が 入ります。ディスプレイ間の隙間や外側の余白を数値で設定する項目はありません。

見る位置を決める

  • センターに移動 — 今の向きを正面にします。基準にするディスプレイを 指定しておくと、そのディスプレイが正面に来ます。
  • 1画面に集中 — ウォールの中の 1 枚だけを表示します。作業に没入したいときに 使います。上部の画面番号を選び、「全体」でウォールに戻ります。集中先が複数ない場合は この操作パネルが表示されないことがあります。
  • スクリーン距離 — ウォールまでの距離です。物理サイズを保ったまま 動かすので、近いほど大きく見えます。0.5 m より近いと目が疲れやすいので、 短時間の演出向けと考えてください。
  • スクリーンサイズ係数 — 距離とは別に、ウォール全体の物理サイズを調整します。
  • スクリーン湾曲 / 屏風モード — ウォールを手前に湾曲させます。屏風モードを オンにすると、なめらかな曲面ではなくディスプレイの継ぎ目で折れ、屏風のように なります（1 枚のディスプレイの途中で折れることはありません）。

ウィジェット

「ウィジェットを追加」から、時計などの小さなパネルをウォールの縁に 貼り付けられます。タイルのクリックで表示 / 非表示、ドラッグで移動、右下の角を ドラッグしてリサイズ、右クリックで設定を開きます。

仮想ディスプレイ

物理的なディスプレイが足りなくても、仮想ディスプレイを追加すればウォールを 広げられます。「Display Wall」下部の「仮想ディスプレイ」で解像度を選び、 「追加」を押します。配置図の空いているところを右クリックして追加することもできます。 追加後は仮想ディスプレイのタイルを右クリックすると、解像度の変更や削除ができます。

Windows では専用のドライバーが要ります（nyan Real / Virtual Display Driver を推奨、ParsecVDisplay も使えます）。ドライバーは同梱していないので、 別途インストールしてください。Linux / macOS では OS 組み込みの機能を使うため、 導入するものはありません。

追加した仮想ディスプレイは、このアプリが動いている間だけ存在します。次回 起動時には前回の構成が復元されます。

仮想ディスプレイの追加・削除は、その1枚だけを増減します。複数あるうちの1枚を 削除しても残りは動作を続け、0枚にした後で追加すれば自動的に動作を再開します。 この増減で全体が「待機」になることはありません。

接続構成ごとの動き

以下では、G は認識されたメガネ画面、V は Spatial Wall が追加した仮想ディスプレイ、 N はそれ以外の通常ディスプレイを表します。N と V は複数でも同じ扱いです。

接続構成 マスタースイッチがオンのとき メイン画面 オフ、またはメガネ画面が切れたとき
G のみ ウォールに出す N / V がないため、ウォール出力は待機します G（Piは該当なし） 変化なし
G + N N を G 上のウォールへ表示します N G 上のウォールだけを止め、N はそのまま使えます
G + V V の映像を G へ実際に表示できてから動作を切り替えます Windows / GNOME / macOS では V へ自動切り替え。Pi にはメイン画面の概念がありません 退避先の N がないため、V は安全のため自動で待機します。再びオンにすると復元します
G + N + V N と V を同じウォールへ表示します 通常は N。Windows / GNOME / macOS では「Display Wall」の配置図で N または V を右クリックして変更できます Windows / GNOME / macOS は N へ戻して V を維持します。Windows / macOS は再びオンにした後、明示した選択も復元します。GNOME では選び直します。Pi は V を待機させます

V を自動でメイン画面にするのは、G が1台、Vが1台以上、Nなしで、現在のVの映像を Gへ表示できたことを確認した場合だけです。Nがある構成やメガネ画面が複数ある構成では 自動でVへ切り替えません。Windows の Direct HMD 出力ではGがデスクトップ外にあるため、 この表ではなくHMD出力側の動作になります。

「メインディスプレイに設定」で V を選ぶには、その画面がウォールに含まれ、メガネで 表示できる必要があります。スリープ中や1画面への集中中は選べません。GNOME では、V の 選択は現在の起動中だけ有効で、マスターオフやメガネ切断、アプリの再起動後は選び直します。 アイドルスリープからの復帰では選択を維持します。Pi には OS のメイン画面の概念がありません。

待機と再開

仮想ディスプレイはメガネ越しでしか見えないので、メガネを外している間は そこに置いたウィンドウが行方不明になります。待機にして窓を回収を押すと、仮想ディスプレイを 一時的に取り外します。OS は、そこに表示されていたウィンドウを残ったディスプレイへ 移動します。再開して窓を戻すを押すと、前回の仮想ディスプレイ構成を復元し、回収した ウィンドウを戻します。待機操作はウォールを表示している間は使えないため、先にマスターを オフにしてください。再開はメガネなしでも使えます。メガネをかけてマスタースイッチを オンにした場合も自動で再開します。

通常、Nが残っていれば、マスタースイッチをオフにしたりメガネを取り外したりしただけでは Vを待機させません。見えない画面はウォールマップから操作できます。例外は、G + Vのように 安全な退避先がなくなる場合とPi版です。また、PC本体がスリープするときは、画面構成を壊さない ためにVを一時的に待機させ、復帰後に物理ディスプレイが安定してから再開することがあります。

ウォールマップ

ウォール全体を小さな平面図として表示するウィンドウです。仮想ディスプレイもそのまま マウスで操作できるので、メガネを外したままでも作業を続けられます。ホイールで 拡大縮小、ドラッグで移動、ダブルクリックで全体表示です。

Windows、Raspberry Pi、macOS では、ウォールマップを表示するための通常ディスプレイが 必要です。メガネへウォールを表示中はメガネ画面も使えないため、G + V や G + V + V のように N がない構成ではスイッチが無効になります。マスターをオフにすると、デスクトップに戻った G を使える場合があります。GNOME では Shell 連携が有効なら、仮想ディスプレイにも ウォールマップを表示できるため、N がない構成でも使えます。

ウォールマップを閉じても、このウィンドウが閉じるだけです。仮想ディスプレイは切断されません。 仮想ディスプレイの切断と復帰には 待機にして窓を回収 / 再開して窓を戻すを使います。

カーソルが迷子にならないように

Windows 版 / macOS 版では、メガネ画面と仮想ディスプレイにそれぞれ「カーソルを入れない」設定があります。 オンにすると、カーソルはその画面を通り抜けて反対側のディスプレイへ移動します。 仮想ディスプレイ側の「メガネで見えない間はカーソルを入れない」は、スリープ中やメガネ未接続時など、 画面が見えない間に働きます。1画面へ集中しているときは、表示中の仮想ディスプレイを操作でき、 それ以外の見えない仮想ディスプレイへの侵入を防ぎます。Android ブリッジでも同じ扱いです。 メガネが HMD としてデスクトップから外れている間は、メガネ側の設定は不要なので表示されません。 macOS では初回に「入力監視」の許可が必要です。GNOME 版と Raspberry Pi 版では OS の入力制御が 異なるため、この設定は表示されません。

ヒント：カーソルが時々隣のディスプレイの端へ飛ぶときは、Windows の ［設定］→［システム］→［ディスプレイ］→［複数のディスプレイ］→ 「ディスプレイ間でカーソルを簡単に移動できるようにする」をオフにしてください。 Windows 側の斜め移動補正と干渉しています。

音

出力先

「Audio Wall」の「音声の出力先」で、Spatial Wall の音を再生するデバイスを選びます。 「メガネに自動」にすると、メガネの USB オーディオを検出したときに 1 回だけ 切り替えます。特定のデバイスを選んだ場合は、そのデバイスが未接続の間も選択を 覚えていて、見つかり次第戻ります。

音量とミュートは上部の操作パネルで変更します。Android ブリッジが出力中は、 この操作がスマホのメディア音量に切り替わります。

Audio Wall

「Audio Wall」のカテゴリで空間音響をオンにすると、音を鳴らして いるアプリを自動で見つけ、そのウィンドウがある方向から聞こえるように混ぜます。 アプリごとの設定は要りません。混ぜたくないアプリは除外リストに実行ファイル名を 入力します（例：discord.exe）。

音はアプリ単位で方向が決まります。1 つのアプリが複数の画面にまたがっている 場合は、1 方向にまとまります。

ブラウザのタブ

Chrome / Edge 116 以降に拡張機能「nyan Real Audio Wall connector」を入れると、タブごとの音も空間に配置できます。Windows、Linux、macOS に 対応しています。DRM メディアと CORS 許可のない別オリジンのメディアは、通常どおり ブラウザから再生され、空間化されません。Web Audio で直接生成された音声も取り込めない 場合があります。

操作する

ショートカットキー（「リモコン操作」→「ショートカットキー」）

センターに移動、集中の切り替え（次 / 前 / 解除）、3DoF とマスタースイッチのオン・オフを Windows、Raspberry Pi（labwc）、macOS ではグローバルホットキーに割り当てられ、 他のアプリを使っている間でも効きます。macOS のマスタースイッチ用ショートカットは既定で Control + Shift + Esc です。GNOME 版はグローバルショートカットの登録に未対応のため、 この設定行は表示されません。

スマホリモコン（「リモコン操作」）

同じネットワーク上のスマホを、タッチパッド付きのリモコンにできます。有線 LAN の PC と Wi-Fi のスマホのように、接続経路が違っても同じネットワーク上で利用できます。 表示される QR コードをスマホのカメラで読み取るだけで、アプリのインストールは 要りません。マウス操作、文字入力、センターに移動、ジャイロの再較正、画面への集中、 音量の変更ができます。キーボードボタンからスマホ側で文字を入力し、PC の入力先へ送信します。 リモコンの設定画面では「Display Wall」に配置図、センターの基準、スクリーン距離・ サイズ係数・湾曲などをまとめています。

QR コードを読み取れない状況（メガネが唯一のディスプレイのときなど）では、コードで ペアリングを使ってください。スマホのブラウザで URL を開き、表示された 6 桁のコードを入力します。

初回に有効化したとき Windows のファイアウォールが確認を出したら、 「アクセスを許可する」を選んでください。同じ LAN 上の端末から利用してください。 URL に含まれるトークンを知らない端末からの操作は拒否されます。

スマホリモコン、Android アプリのダウンロード、メガネブリッジは LAN 内で 暗号化されていない HTTP / WebSocket を使用します。共有 Wi-Fi や公衆 Wi-Fi ではなく、 信頼できる私設ネットワークでのみお使いください。

Android メガネブリッジ（「リモコン操作」）

メガネを PC ではなく Android スマホへ接続して使う方法です。スマホ側のアプリが メガネとの USB 接続を担当し、映像と頭の向きを PC のウォールへ中継します。PC の USB ポートを 占有したくない場合や、PC から離れて使いたい場合に向いています。メガネを Android の 外部ディスプレイ（Presentation）として扱い、映像と音声を送る機能は Windows と macOS に 対応しています。macOS では画面収録と音声収録の許可が必要です。検証済みの構成と 既知の制限は付録にまとめています。 高画質モードと外部 Video Input は Windows 専用です。 Windows では「リモコン操作」→「Android メガネブリッジ」で「高画質モード」を設定できます。 文字や細部を鮮明にできますが、画面が大きく変化すると通信量が増えます。

スマホのアプリが接続すると、「リモコン操作」に接続状態が表示されます。 メガネの明るさ・表示モード・外部ディスプレイの状態や、IMU と映像チャンネルが つながっているかを、PC 側から確認できます。ブリッジ経由でも、機種ごとの設定は PC に直接つないだときと同じように扱われます。

Stream Deck（「リモコン操作」→「Stream Deck」）

「この PC からの操作を受け付ける」をオンにすると、ループバック専用 （127.0.0.1）の制御ポートが開き、Stream Deck 用のプラグインからホットキーと 同じ操作ができます。他の PC からは届かないので、トークンはありません。

ログイン時に起動（「詳細」）

Windows 版、パッケージ導入した Linux 版、macOS の .app では、ログイン時に自動起動できます。 macOS では承認のため「システム設定」→「一般」→「ログイン項目」が開くことがあります。 コントロールウィンドウの表示・非表示は前回の状態を引き継ぎます。ログイン時に常駐アイコンだけに したい場合は、ウィンドウを閉じておきます。常駐アイコンからいつでも再表示できます。

見え方と負荷の調整

滑らかさ（「省電力」）

  • 壁キャプチャ更新頻度 — キャプチャの上限です。「自動」で足りますが、 負荷を下げたいときは 45 Hz や Eco（30 Hz）にできます。
  • フレームスキップ — 何も動いていない間の描画を省いて電力を節約します。 PC に余裕があるなら、オフにしたほうが動き出しが滑らかです。

画質（「映像エフェクト」）

  • バンディング低減（デバンド） — 暗いグラデーションに出る縞を減らします。
  • 輪郭スムージング — 文字や線のちらつきを抑えます。

残像とちらつき（メガネ）

  • 低残像 Duty — 頭を動かしている間だけ OLED のデューティ比を下げ、残像を 減らします（その分暗くなります）。XREAL Air / Nreal Light が対象です。
  • フルスクリーン排他（Windows の「詳細」） — 通常は不要です。スキャンアウトが定格の Hz を 下回る構成（一部の NVIDIA ハイブリッド環境など）でだけ試してください。 デスクトップ出力専用で、DisplayCore を使用する HMD モード中は無効になります。

外観（「外観」）

表示言語は「自動（OSに合わせる）」が既定です。日本語または英語を明示的に 選ぶこともできます。変更時に案内が出るので、Spatial Wall を再起動すると 新しい言語が反映されます。

テーマは「自動（OSに合わせる）」「ライト」「ダーク」から選べます。Ubuntu 24.04の 標準Qt 6.4では「自動」はライト表示になり、OS側での変更には追従しませんが、ライトと ダークは手動で切り替えられます。

困ったとき

メガネが検出されない

  • USB ケーブルが映像とデータの両方を通すものか確認してください。充電専用の ケーブルでは検出できません。
  • XREAL One 系では、メガネ側の USB Ethernet（TCP/IP）が有効である必要があります。 無効だと 3DoF が機能しません（メガネ内に案内が表示されます）。
  • DP オーディオモードになっていると、センサーデータを取得できません。USB オーディオへ 切り替えてください。

メガネに何も映らない / デスクトップが消えた

  • 通常の拡張画面として使う場合は、表示が「複製」や「セカンドスクリーンのみ」に なっていないか確認してください。「メガネを拡張ディスプレイに固定」をオンにすると Windows では対応メガネの物理ターゲットを識別し、無効化や複製状態を接続のたびに自動で直します。
  • HMD 対応モードへの切り替え後に暗いままなら、「保存した表示モードを接続時に復元」を オフにし、ケーブルを抜き差ししてください。それでも通常画面へ戻らなければ Windows を 再起動してください。終了時に通常画面への復帰を確認している間は、アプリを強制終了しないでください。
  • GPU ごとの HMD 直接出力の確認状況は、付録の「検証済み構成と既知の制限」を確認してください。

カクつく・コマ落ちする

  • 「壁キャプチャ更新頻度」を下げてみてください。
  • フレームスキップをオフにすると、動き出しが滑らかになることがあります。
  • 通常のデスクトップ出力でスキャンアウトが 60 Hz に落ちている疑いがあるときだけ、フルスクリーン排他を 試してください。

音が出ない / 音の向きがおかしい

  • 「音声の出力先」がメガネになっているか確認してください。
  • Audio Wall の音はアプリ単位です。ウィンドウを目的のディスプレイへ移動すると 方向が変わります。
  • Audio Wall を使用する場合は、Windows の既定の出力デバイスを、実際の再生には 使わないデバイスへ設定してください。既定の出力と Spatial Wall の出力が重なると、 音が二重に聞こえます。

カーソルが行方不明になる

Windows 版と macOS 版では「カーソルを入れない」設定をオンにしてください。macOS では初回に 「入力監視」の許可が必要です。GNOME 版、Raspberry Pi 版、またはカーソルがすでに 見えない画面へ移動した場合は、ウォールマップから操作できます。

macOS で Control + Shift + Esc を押すとマスタースイッチがオフになり、 メガネ上の Spatial Wall の表示が消えます。Spatial Wall が管理する仮想ディスプレイが メインディスプレイになっている場合は、表示を消す前に、メインディスプレイを 表示を確認できる物理ディスプレイへ戻します。

それでも解決しないとき

「バージョン情報」の「問い合わせ用情報をコピー」を押すと、製品名・バージョン・ OS、実際に使用中のGPUと取得可能なドライバーバージョン、接続中のメガネと実行状態、 画面構成、仮想ディスプレイの方式・状態、問い合わせへの 掲載を許可した現在の設定値がクリップボードに入ります。nyan Real / Virtual Display Driver 使用時は、ドライバとアプリのプロトコルバージョンも含まれます。接続トークン、保存先パス、 画面や音声デバイスの識別子など、個人情報や秘密情報になり得る設定値は含まれません。 問い合わせフォームの 「問い合わせ用情報」欄へ内容を変えずに貼り付け、OS を選択し、対応メガネの機種名を 入力したうえで、「症状」と 「再現手順」をそれぞれの欄へ記入してください。ログや画像を添付するときは、 個人情報や秘密情報が含まれていないことを確認してください。

設定の保存場所

設定とログは %APPDATA%\nyan-real\（Linux / macOS では各 OS のユーザー設定 ディレクトリ）の下に保存されます。ログの保存先フォルダーはアプリ内から開けます。

設定を初期化する

「詳細」の「設定を既定値に戻す」で、すべての設定が初期状態に戻ります。 元には戻せません。

バージョンの確認

「バージョン情報」にバージョンとビルド時刻が出ます。spatial-wall.exe を右クリックして ［プロパティ］→［詳細］でも確認できます。
